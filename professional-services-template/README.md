# Professional services template — Bramwell Cole Advisory

A credibility-forward template shell for firms that sell expertise
(consulting, accounting, legal-adjacent advisory). Static HTML/CSS, no
build step, no dependencies.

## What's placeholder

Everything with a `.example` domain, the firm name, and both partner
bios are fictional — swap these for the real firm's details:

- `index.html` — firm name, tagline, practice areas, team bios,
  client quote, contact email (`mailto:` link)
- Favicon in `<head>` if the new brand needs a different mark

## Design notes

Deep ink-navy on warm paper, a single brass accent used only for the
kicker text, the pull-quote rule, and the CTA underline — never a
bright button. Newsreader (display serif) + Inter (body sans), the
inverse pairing from the local-service template. Left-aligned,
letterhead-style layout rather than a centered hero, on purpose: this
firm sells judgment, not a product shot.

## Local preview

Open `index.html` directly in a browser, or serve the folder with any
static file server (e.g. `npx serve .`).
