Knowledge-base Q&A

Ask a question and a server-side call to Claude answers it using only a fixed set of documents, then shows exactly which document and section the answer came from. Ask something the documents don't cover and it says so instead of guessing.

This demo answers from four fictional documents about a made-up scheduling product, Northbound Scheduler: an FAQ, a Refund & Cancellation Policy, a Getting Started Guide, and a Product Overview & Features page.

This demo uses keyword retrieval over a small fixed set of documents to keep it fast and free to try. A production build uses vector embeddings and semantic search over your full document set.
